# Lakshay Gupta portfolio (React 19 + Vite 8 + Tailwind 4)

- Content: `src/data.js` (text, links, skill levels). Layout: `src/App.jsx`. Theme: `src/index.css`.
- Photo: put `profile.jpg` in `public/` (portrait, about 960x1120). Until then `public/profile-placeholder.svg` shows.
- Resumes: `public/resume-data-analyst.pdf` and `public/resume.pdf` (full-stack).
- Run: `nvm install 24 && nvm use` then `npm install`, `npm run dev`, `npm run build`.
